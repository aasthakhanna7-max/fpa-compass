# The FP&A Compass

A one-stop FP&A knowledge hub by Aastha Khanna.

- **Core concepts**: FP&A topics in a step-by-step learning path, with formulas, worked examples and interactive calculators
- **Case studies**: planning transformations with interactive demos
- **Excel templates**: formula-driven workbooks (variance reporting, PVM, 13-week cash, rolling forecast, AOP, headcount, capex, month-end close)
- **Interview prep**: top FP&A interview questions with model answers, practice mode and a free PDF guide
- **Blog and quiz**

The site is a single static page (`index.html`). Templates and the interview guide are in `templates/`.
